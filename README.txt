僕が見たかった青空 タイピングゲーム

起動方法:
1. このフォルダ内の index.html をブラウザで開きます。
2. 「ゲームスタート」を押して遊びます。

画像の設定:
assets フォルダにメンバーの写真を入れてください。
script.js 内の各メンバーの image と一致するファイル名にします。
例: 安納蒼衣.jpg、伊藤ゆず.jpg、塩釜菜那.jpg
元のスクリーンショットは member-photo-reference.png として同梱していますが、
スクリーンショットから個別写真を切り出す処理はしていません。
写真がない場合も、プレースホルダーでゲームは動作します。

注意:
メンバー名の読み・ローマ字はゲーム用設定です。必要に応じて script.js の members 配列を修正してください。
